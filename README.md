# Number Guessing Game using Python

## Project Title

Number Guessing Game using Python

## Project Description

This is a real-world number guessing game developed using Python. In this game, the computer randomly selects a number between 1 and 100, and the user tries to guess it.

The program provides hints such as "Too high" or "Too low" after each guess. It also counts the number of attempts and allows the user to play multiple rounds.

## Technologies Used

* Python
* Visual Studio Code
* GitHub

## Features

* Random number generation
* User input
* Too high and too low hints
* Attempts counter
* Invalid input handling
* Multiple rounds
* Clear result display

## Setup Instructions

### 1. Install Python

Install Python on your computer.

### 2. Download or Clone the Repository

Download this project from GitHub.

### 3. Open the Project

Open the project folder in Visual Studio Code.

### 4. Run the Program

Open the terminal and run:

```bash
python guessing_game.py
```

### 5. Play the Game

Enter a number between 1 and 100.

The program will tell you whether your guess is too high or too low.

Continue guessing until you find the correct number.

After the round ends, you can choose whether to play again.
